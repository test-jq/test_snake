# Snake Game

Ce projet est une implémentation simple du jeu Snake en Python avec Pygame.

## Prérequis
- Python 3.x
- Pygame

## Installation
1. Clonez ce dépôt ou copiez les fichiers dans un dossier local.
2. Installez les dépendances avec pip :

    pip install -r requirements.txt

## Lancement du jeu
Exécutez simplement le fichier snake.py :

    python snake.py

## Tests
Des tests unitaires sont disponibles pour vérifier la logique du jeu et le lancement :

    python -m unittest test_snake.py

## Fonctionnalités
- Le serpent grandit en mangeant des pommes.
- Le jeu se termine si le serpent se mord la queue.
- Score affiché dans la console à la fin de la partie.
